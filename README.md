# SHL Sem Medo

Página de vendas de Emanoel Lourenço, em HTML, CSS e JavaScript.

## Editar

- `index.html`: textos, seções, oferta, links e GTM.
- `assets/styles.css`: cores, tipografia e layout responsivo.
- `assets/app.js`: carrossel manual de depoimentos.
- `assets/`: imagens utilizadas na página.

Não há dependências, instalação ou etapa de build. A hospedagem usa GitHub Pages a partir da raiz da branch principal. O destino de domínio escolhido é `shl.operfilexplicacomissario.com.br`.

O container GTM do projeto está incluído no código. As condições comerciais e o checkout devem ser conferidos ao atualizar a oferta.
